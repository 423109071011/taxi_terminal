## 1. 总体架构

单进程多线程的分层 C 程序，四层职责自上而下：

```
业务层   biz/taxi.c        认证·位置上报·疲劳计时·刷卡密码（什么时候动）
服务层   svc/*             网络管理·下行分发·显示调度·状态灯·命令行
硬件抽象 hal/*             一设备一文件，封装设备节点（怎么动）
设备节点 /dev/*            event4·i2c-2·rfid0·ttyUSB1·socket ...
```

横切支撑：`shared/jt808.c` 协议编解码（**终端与平台端共用同一份源码**，保证双方对帧格式理解零分歧）；`common/app_state` 单一全局状态结构体 + 互斥锁做线程安全。

**并发模型**：多线程事件驱动——网络任务、1 秒兜底心跳、RFID 轮询、按键输入、蜂鸣、烟雾、空闲轮播、状态灯各一线程，靠 `app_state` + `st->lock` 互斥锁交换数据，事件驱动为主，无阻塞式主循环轮询。

**答辩亮点**：分层解耦（换平台只改 `taxi.conf`，换硬件只改 HAL）；协议库单源双端共用；注册表式显示管理（加显示项只需注册一个 getter）。

## 2. 模块与硬件资源

### 2.1 I2C 总线 2（2 个从设备，3 个功能）

| I2C 从设备 | 驱动 | 功能/设备节点 |
|---|---|---|
| ZLG72128 键盘数码管控制器 | `key-zlg72128.ko` | 键盘：input 设备 `i2cKEY`（`/dev/input/event4`）；数码管：`/dev/zlg72128-0` |
| RFID 读卡模块（地址 2-0019） | 厂商驱动 | 读卡：`/dev/rfid_module0` |

注意：单设备接触不良会卡死整条总线（键盘+读卡一起失灵），处置为整机断电 10 秒；`key-zlg72128.ko` 与 `zlg7290.ko` 不可同时 insmod（I2C 地址冲突）。

| 模块 | 接口 | 设备节点 |

## 5. 数码管显示体系

**页系统**（display_mgr 注册表，格式 `类型号-数值`）：

| 页 | 名称 | 数值含义 |
|---|---|---|
| 0 | CARD | 卡号十进制后六位（如 `0-925168`） |
| 1 | VERIFY | 验证 0=未验 1=通过 2=拒绝 |
| 2 | DOOR | 车门 0=关 1=开 |
| 3 | FATIGUE | 疲劳 0=正常 1=报警 |
| 4 | NET | 4G 0=离线 1=在线 |
| 5 | GPS-SATS | 卫星颗数 |
| 6 | SMOKE | 烟雾 0=正常 1=超标 |
| 7 | DRIVE | 连续驾驶分钟数 |

手动翻页（A/B 键）控制台同步输出 `[类型号 名称] = 数值`；10 秒无按键自动轮播每 3 秒一项、控制台静默（验收规格 §B）。

**事件整屏**（不走页系统，直接覆盖）：刷卡=整屏卡号十进制；密码输入=只显已输数字按序左对齐；平台 0x8110 应答=PASS/FAIL；D 键解除=OK；开机清屏去残留。整屏直写驱动仅支持 8 位，超长内容右对齐截取。

## 6. 认证流程要点（0x0210）

- 消息体 = **卡号 10B ASCII 十进制（4B 大端 UID 换算，前导 0 补齐）+ 密码 ASCII**，同一帧同时发送；平台按定长切分（前 10 字节卡号，其余为密码）。测试卡 `0D 0E 0F 10` → `0219025168`。
- 刷卡单独**不发帧**不开门；只输密码不刷卡按确认，终端本地拒绝不发帧。
- **刷卡有效期 30 秒**：超时确认照发帧但卡号字段全 0（`0000000000`）仅带密码，平台按无卡拒绝。
- 开门唯一途径 = 平台 0x8110 体 0x00；PASS 同时启动疲劳计时（默认 240 分钟，C 键关门停表，D 键解除重置）。

## 7. 找代码的技巧

- 定位某函数：`grep -n "函数名" src/biz/taxi.c`
- 跨文件找功能关键词（PASS、0x8110、fatigue）用全仓 grep 最快
- 行号仅当前版本有效，**函数名是稳定索引**；改过 `.h` 必须 `make clean && make` 全量重编（Makefile 无头文件依赖）
