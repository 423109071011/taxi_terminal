# 平台下发测试帧（联调用）

按 `shared/jt808.c` 的 `jt808_build()` 规则逐字节生成，异或校验已算好，可直接粘贴到网络调试助手发送框。

## 帧结构

```
7E | 消息ID(2) | 消息体属性(2) | 终端手机号BCD(6) | 终端ID BCD(6) | 流水号(2) | 封装项(4=全0) | 消息体 | 校验 | 7E
```

- 校验：从「消息ID」到「消息体最后一字节」逐字节异或
- 转义：帧中间出现 0x7E→`7D 02`、0x7D→`7D 01`（头尾 7E 不转义）
- 本终端：手机号 = 终端ID = `091111222200`

## 测试帧

| 用途 | 帧（十六进制） |
|---|---|
| 疲劳驾驶 ON（蜂鸣器间歇响） | `7E8210000109111122220009111122220000010000000001937E` |
| 疲劳驾驶 OFF | `7E8210000109111122220009111122220000020000000000917E` |
| 蜂鸣器 ON | `7E88110001091111222200091111222200000300000000019A7E` |
| 蜂鸣器 OFF | `7E88110001091111222200091111222200000400000000009C7E` |
| 身份验证 PASS（显示屏 PASS + 舵机开门 90°） | `7E8110000109111122220009111122220000050000000000957E` |
| 身份验证 FAIL（显示屏 FAIL，不开门） | `7E8110000109111122220009111122220000060000000001977E` |
| 平台通用应答 0x8001（示意） | `7E800100050911112222000911112222000007000000000001020000807E` |

## 消息体取值（易错）

| 消息号 | 含义 | 消息体 | 效果 |
|---|---|---|---|
| 0x8210 | 疲劳驾驶 | `00`/`01` | `01`=ON，`00`=OFF |
| 0x8811 | 蜂鸣器控制 | `00`/`01` | `01`=响，`00`=停 |
| 0x8110 | 身份验证应答 | `00`/`01` | **`00`=PASS（开门）**，`01`=FAIL |
| 0x8001 | 平台通用应答 | 应答流水号(2)+应答消息ID(2)+结果(1) | 终端仅打印 |

> 注意 0x8110 的语义与直觉相反：`b[0] == 0` 才是验证通过（见 `taxi_handle_auth_resp`）。

## 终端对平台下发帧的约定行为

收到 0x8001~0x9FFF 区间的下发消息后，终端会回一帧 **0x0001 终端通用应答**（携带原帧流水号），调试助手上应能看到回包，可据此确认终端确实收到了。
