# 出租车终端协议清单（上行 · 下行）

> 更新日期：2026-09-23。依据：`shared/jt808.c` 实际实现 + 《JH车载定位数据协议_V0.1》。本文与代码逐项核对过，平台侧可直接按此解析。

---

## 1. 帧格式（所有消息共用）

```
7E | 消息ID(2) | 消息体属性(2) | 终端手机号(6) | 终端ID(6) | 流水号(2) |
  | 消息包封装项(4) | 消息体 | 校验码(1) | 7E
```

| 字段 | 长度 | 说明 |
|---|---|---|
| 帧头标识 | 1 | 固定 `0x7E` |
| 消息 ID | 2 | 见第 2/3 节 |
| 消息体属性 | 2 | bit0~11 = 消息体长度；bit13 = 分包标志（恒 0，不分包）；bit14~15 保留 |
| 终端手机号 | 6 | BCD，`091111222200` |
| 终端 ID | 6 | BCD，`091111222200`（与手机号相同） |
| 流水号 | 2 | 发送方自增，平台应答时回填 |
| 消息包封装项 | 4 | DWORD，不分包恒 `0x00000000`（**必传**，缺了终端整帧丢弃） |
| 消息体 | 变长 | 大端序，布局见各消息 |
| 校验码 | 1 | 从消息 ID 至消息体最后一字节**逐字节异或** |
| 帧尾标识 | 1 | 固定 `0x7E` |

**转义规则**（收发双向实现，头尾 7E 不转义）：`0x7E → 0x7D 0x02`，`0x7D → 0x7D 0x01`。

**接入方式**：终端为 TCP 客户端主动连平台；心跳 1 秒/帧，平台读空闲超时 ≥180 秒；断线终端每 2 秒自动重连。

## 2. 上行消息（终端 → 平台）

### 2.1 `0x0200` 位置报警信息汇报（34B）★心跳

**频率**：1 秒/帧；车门开/关、烟雾报警置/除、疲劳置/除、D 键解除、认证开门等**状态变化时立即补发**。

| 偏移 | 字段 | 长度 | 说明 |
|---|---|---|---|
| 0 | 报警标志 | 4 | bit0=烟雾/紧急报警(0x01)；bit2=疲劳驾驶(0x04)；其余 0 |
| 4 | 状态 | 4 | bit1=已定位(0x02)；bit12=车门加锁(0x1000)；bit13=门1开(0x2000)；bit18=GPS定位(0x40000) |
| 8 | 纬度 | 4 | 度 ×1e6，大端整数 |
| 12 | 经度 | 4 | 度 ×1e6，大端整数 |
| 16 | 高程 | 2 | 恒 0 |
| 18 | 速度 | 2 | km/h（GPS 实速；uppath 历史文件第 5 列） |
| 20 | 方向 | 2 | 恒 0 |
| 22 | 时间 | 6 | BCD `YYMMDDhhmmss`，**UTC**（北京时间 −8h，跨日自动借位） |
| 28 | 附加项 ID | 1 | `0x01` 里程 |
| 29 | 附加项长度 | 1 | `0x04` |
| 30 | 里程 | 4 | 恒 0 |

> 历史轨迹（uppath）：帧内时间用**文件里的历史时间**（`YYMMDD HHMMSS` 或 `HH:MM:SS` 格式均可），历史点强制置位 bit1+bit18；无速度列时速度保持 GPS 实速。

### 2.2 `0x0210` 司机身份验证请求（自定义）

**时机**：刷卡 + 输入密码 + 按"确认"完整操作后**一帧同时携带卡号与密码**；刷卡或输密码单独都不发帧。

| 偏移 | 字段 | 长度 | 说明 |
|---|---|---|---|
| 0 | 卡号 | 10 | ASCII 十进制定长（4B 大端 UID 合成 32 位整数再转十进制，前导 0 补齐）。测试卡 `0D 0E 0F 10` → `0219025168` |
| 10 | 密码 | ≤6 | ASCII，**必非空**（空密码终端本地拒绝不发） |

**特殊情况**：刷卡后超 **30 秒**才确认 → 帧照发，但卡号字段填全 0（`0000000000`）仅带密码，平台按无卡拒绝。未刷卡按确认、空密码按确认：终端本地拒绝，**不发任何帧**。

### 2.3 `0x0001` 终端通用应答（5B）

**时机**：收到平台每条 0x8xxx 消息**必回**。

| 偏移 | 字段 | 长度 | 说明 |
|---|---|---|---|
| 0 | 应答流水号 | 2 | 对应平台消息帧头中的流水号 |
| 2 | 应答 ID | 2 | 对应平台消息的消息 ID |
| 4 | 结果 | 1 | 0=成功；其他=失败 |

## 3. 下行消息（平台 → 终端）

### 3.1 `0x8001` 平台通用应答（5B）

| 字段 | 长度 | 说明 |
|---|---|---|
| 应答流水号 | 2 | 对应终端消息的流水号 |
| 应答 ID | 2 | 对应终端消息的消息 ID |
| 结果 | 1 | 0=成功 |

终端行为：正常静音（每秒心跳都有应答）；**结果 ≠0 时串口提示**并回 0x0001。

### 3.2 `0x8110` 身份验证应答（自定义，≥1B）★唯一开门指令

| 字段 | 长度 | 说明 |
|---|---|---|
| 结果 | 1 | **0x00 = PASS（开门）**；其他 = FAIL |
| 提示文本 | 变长 | ASCII，可省略 |

终端行为：
- **PASS** → 舵机开门（`door_open_angle`，默认 90°）+ 数码管显示 `PASS` + 蜂鸣短响一声 + **启动疲劳驾驶计时** + 立即补发 0x0200（车门状态位变化）；
- **FAIL** → 数码管显示 `FAIL`，门不开。

### 3.3 `0x8210` 疲劳驾驶下发（自定义，1B）

| 字段 | 长度 | 说明 |
|---|---|---|
| 状态 | 1 | 1=疲劳报警；0=解除 |

终端行为：1 → 蜂鸣周期响 + 报警标志 bit2 置位 + LED 报警序列 + 补发 0x0200；0 → 解除。
注意：终端**本地也独立计时**（PASS 开门起 240 分钟），不完全依赖 0x8210。

### 3.4 `0x8811` 蜂鸣器直控（1B）

| 字段 | 长度 | 说明 |
|---|---|---|
| 控制 | 1 | 0x01=开；0x00=关 |

终端行为：直接 ioctl 蜂鸣器，**不经过业务标志位**；D 键解除报警时会显式补发关蜂鸣。

## 4. 消息 ID 速查表

| 方向 | 消息 ID | 名称 | 触发时机 |
|---|---|---|---|
| 终端→平台 | 0x0200 | 位置汇报 | 1s 心跳 + 状态变化即时 |
| 终端→平台 | 0x0210 | 身份验证请求 | 刷卡+密码+确认（卡号密码同帧） |
| 终端→平台 | 0x0001 | 终端通用应答 | 每条 0x8xxx 必回 |
| 平台→终端 | 0x8001 | 平台通用应答 | 对终端每帧应答 |
| 平台→终端 | 0x8110 | 身份验证应答 | 裁决 0x0210（唯一开门指令） |
| 平台→终端 | 0x8210 | 疲劳驾驶下发 | 手动/定时 |
| 平台→终端 | 0x8811 | 蜂鸣器直控 | 手动 |

**不要求**：0x0100 注册 / 0x0102 鉴权（终端未实现，平台无需等待）。
