# platform —— PC 模拟平台

用于和终端联调的简易 JT808 服务端。**当前提供 Python 版**，零依赖，Linux / Windows 都能跑。

## 文件

| 文件 | 说明 |
|---|---|
| `src/fake_platform.py` | 模拟平台主程序（监听 TCP、收帧、解析、下发指令）|
| `shared/jt808.c` `jt808.h` | 编解码共用源码（与终端同一份，C 语言版平台可直接引用）|

## 运行

```bash
python3 platform/src/fake_platform.py 8888
```

Windows 上把 `python3` 换成 `python`。

## 命令行命令

| 命令 | 作用 |
|---|---|
| `help` | 显示帮助 |
| `list` | 列出已连接的终端 |
| `fatigue 1` | 下发疲劳驾驶 = 1，终端蜂鸣器开始周期报警 |
| `fatigue 0` | 下发疲劳驾驶 = 0，解除报警 |
| `strict 1` | 身份验证按白名单校验（卡号 + 身份码）|
| `strict 0` | 身份验证全部放行（默认）|
| `quit` | 退出 |

## 司机白名单

在 `fake_platform.py` 顶部的 `DRIVERS` 字典里改：

```python
DRIVERS = {
    "11223344": "123456",
    "AABBCCDD": "888888",
}
```

左边是 RFID 卡号（4 字节十六进制，大写），右边是键盘要输入的身份码。

## 与终端的对应关系

| 方向 | 消息号 | 名称 |
|---|---|---|
| 终端 → 平台 | `0x0200` | 位置信息汇报 |
| 终端 → 平台 | `0x0210` | 司机身份验证请求（卡号4B + 身份码ASCII）|
| 平台 → 终端 | `0x8110` | 身份验证应答（结果1B：0准许/1拒绝 + 提示文本）|
| 平台 → 终端 | `0x8210` | 疲劳驾驶状态下发（状态1B：0解除/1疲劳）|

## 注意

- 终端 `deploy/config` 里的 `server_ip` 必须改成**运行本程序那台机器的 IP**。
- 帧格式、异或校验、转义规则与终端 `shared/jt808.c` 严格一致，可互解。
